## 📦 Экспорт ресурсов

### Изображения и иконки

1. **Экспорт изображений**:
   - Выберите элемент в Figma
   - В правой панели найдите раздел "Export"
   - Рекомендуемые форматы:
     - PNG для изображений с прозрачностью
     - JPG для фотографий
     - SVG для векторной графики и иконок
   - Сохраняйте в папку `public/images/`

2. **Иконки**:
   - Экспортируйте как SVG
   - Сохраняйте в `public/icons/`
   - Или используйте библиотеку иконок (Heroicons, Lucide и т.д.)

### Шрифты

1. Проверьте используемые шрифты в Figma
2. Добавьте их в проект:
   - Google Fonts: добавьте в `index.html`
   - Локальные шрифты: поместите в `public/fonts/`

Пример для Google Fonts:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
```

## 🎨 Извлечение стилей

### Цвета

1. Откройте Figma и найдите раздел "Local styles"
2. Скопируйте цветовую палитру
3. Добавьте в `tailwind.config.js`:

```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#f0f9ff',
          100: '#e0f2fe',
          // ... добавьте все оттенки
          900: '#0c4a6e',
        },
        secondary: {
          // ваши цвета
        }
      }
    }
  }
}
```

### Типографика

Извлеките стили текста из Figma и добавьте в `tailwind.config.js`:

```javascript
module.exports = {
  theme: {
    extend: {
      fontSize: {
        'display-1': ['72px', { lineHeight: '90px', fontWeight: '700' }],
        'heading-1': ['48px', { lineHeight: '60px', fontWeight: '700' }],
        // ... другие стили
      }
    }
  }
}
```

### Отступы и размеры

Стандартизируйте spacing из Figma:

```javascript
module.exports = {
  theme: {
    extend: {
      spacing: {
        '18': '4.5rem',
        '88': '22rem',
        // кастомные значения
      }
    }
  }
}
```

## 🔨 Реализация компонентов

### Процесс работы

1. **Анализ дизайна**:
   - Откройте страницу в Figma
   - Включите Dev Mode (правый верхний угол)
   - Изучите структуру компонентов

2. **Создание компонента**:
   ```tsx
   // src/components/Button.tsx
   interface ButtonProps {
     variant?: 'primary' | 'secondary';
     size?: 'sm' | 'md' | 'lg';
     children: React.ReactNode;
   }
   
   export default function Button({ variant = 'primary', size = 'md', children }: ButtonProps) {
     return (
       <button className={`btn btn-${variant} btn-${size}`}>
         {children}
       </button>
     );
   }
   ```

3. **Использование Dev Mode в Figma**:
   - Выберите элемент
   - Скопируйте CSS/Tailwind классы
   - Адаптируйте под React компонент

### Структура страницы

Пример замены заглушки на реальный дизайн:

```tsx
// src/pages/Home.tsx
export default function Home() {
  return (
    <div>
      {/* Hero Section - из Figma */}
      <section className="...классы из Figma...">
        <h1>Заголовок из дизайна</h1>
        {/* ... */}
      </section>
      
      {/* Features Section */}
      <section className="...">
        {/* ... */}
      </section>
    </div>
  );
}
```

### Responsive дизайн

Убедитесь, что учтены все breakpoints из Figma:

```tsx
<div className="
  w-full 
  md:w-1/2 
  lg:w-1/3
  px-4
  md:px-6
  lg:px-8
">
  {/* контент */}
</div>
```

## 🛠 Полезные инструменты

### Плагины Figma

1. **Figma to Code**:
   - Автоматическая генерация React/HTML кода
   - Поддержка Tailwind CSS

2. **Design Tokens**:
   - Экспорт цветов, типографики
   - JSON формат для импорта

3. **Content Reel**:
   - Быстрое заполнение макетов тестовым контентом

### VS Code расширения

1. **Figma for VS Code**:
   - Просмотр дизайнов прямо в редакторе
   - Копирование CSS

2. **Tailwind CSS IntelliSense**:
   - Автодополнение Tailwind классов
   - Preview значений

### Онлайн инструменты

1. **Figma API**:
   ```bash
   # Получение файла через API
   curl -H "X-Figma-Token: YOUR_TOKEN" \
     "https://api.figma.com/v1/files/FILE_KEY"
   ```

2. **Figma Tokens**:
   - Создайте Personal Access Token
   - Settings → Account → Personal Access Tokens

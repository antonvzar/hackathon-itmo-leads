# ITMO Leads - Hackathon Project

Современный веб-проект, созданный на базе React + TypeScript + Tailwind CSS для хакатона ИТМО.

- **[QUICK_START.md](./QUICK_START.md)** - 🎯 **Начните здесь!** Быстрый старт за 3 минуты

- **[PROJECT_SUMMARY.md](./PROJECT_SUMMARY.md)** - 📊 Обзор проекта и что было сделано
- **[README.md](./README.md)** - 💻 Техническая документация (этот файл)

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск проекта в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Предпросмотр production сборки

```bash
npm run preview
```

## 🎨 Интеграция Figma дизайнов

Проект готов к интеграции дизайнов из Figma. Подробные инструкции смотрите в файле [FIGMA.md](./FIGMA.md).

### Быстрое руководство:

1. **Получите доступ к Figma проекту**
2. **Экспортируйте ресурсы** (изображения, иконки)
3. **Скопируйте стили** (цвета, шрифты) в `tailwind.config.js`
4. **Реализуйте компоненты** на основе дизайна
5. **Замените placeholder контент** на реальный

## 🛠 Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev сервер
- **Tailwind CSS** - utility-first CSS фреймворк
- **React Router** - маршрутизация

## 📝 Заметки для разработки

- Все компоненты используют TypeScript для типобезопасности
- Tailwind CSS настроен и готов к кастомизации
- Проект использует темную/светлую тему (можно расширить)
- Responsive дизайн реализован с помощью Tailwind breakpoints

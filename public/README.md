# Public Assets Directory

## 📁 Структура

```
public/
├── images/     # Изображения из Figma (PNG, JPG)
├── icons/      # Иконки и SVG файлы
├── fonts/      # Локальные шрифты (если нужны)
└── vite.svg    # Favicon
```

## 📋 Инструкции

### Изображения
Сохраняйте экспортированные из Figma изображения в папку `images/`:
- Используйте осмысленные имена файлов (например, `hero-background.jpg`)
- Оптимизируйте размер изображений перед добавлением
- Рекомендуемые форматы: JPG для фото, PNG для изображений с прозрачностью

### Иконки
Сохраняйте SVG иконки в папку `icons/`:
- Экспортируйте иконки из Figma как SVG
- Используйте kebab-case для имен (например, `arrow-right.svg`)
- Оптимизируйте SVG файлы через SVGO

### Шрифты
Если используете локальные шрифты, сохраняйте их в папку `fonts/`:
- Поддерживаемые форматы: WOFF2, WOFF, TTF
- Добавьте `@font-face` правила в `src/index.css`

## 💡 Использование в коде

```tsx
// Изображения
<img src="/images/hero-background.jpg" alt="Hero" />

// Иконки
<img src="/icons/arrow-right.svg" alt="Arrow" />
```

Все файлы в папке `public/` доступны по корневому пути.

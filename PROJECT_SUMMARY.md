## 🚀 Как начать работу

### 1. Установка (2 минуты)
```bash
cd /workspace
npm install
```

### 2. Запуск dev сервера
```bash
npm run dev
```
Откройте: http://localhost:5173

### 3. Начните интеграцию Figma
Читайте: `QUICK_START.md` или `FIGMA.md`
